# Week 01: Todo Application

A simple, elegant todo application built with **TypeScript** and modern **CSS**, designed to be responsive, accessible, and easy to use.

## Features

- Add new todos
- Edit existing todos
- Delete todos
- Persistent storage using LocalStorage
- Fully responsive design
- Modern UI with smooth animations
- Accessible (ARIA labels, keyboard navigation)

## Quick Start

### Prerequisites

- Node.js (v14 or higher)
- npm or yarn

### Installation

1. Navigate to the project folder:

```bash
cd 01_todo_app
```

2. Install dependencies:

```bash
npm install
```

3. Start the development environment:

- Terminal 1: Compile TypeScript

```bash
npm run dev
```

- Terminal 2: Serve the app locally

```bash
npm run serve
```

4. Open your browser at the URL provided by the server.

### Production Build

```bash
npm run build
```

## Usage

### Adding a Todo

1. Type your task in the input field.
2. Press **Enter** or click **Add Task**.

### Editing a Todo

1. Click the edit button (pencil icon) next to a todo.
2. Modify the text in the input field.
3. Press **Enter** to save or **Escape** to cancel.

### Deleting a Todo

Click the delete button (trash can icon) next to a todo.
